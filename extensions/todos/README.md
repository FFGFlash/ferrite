# TODOs

Highlights `TODO` and `FIXME` comments, and lists them in a side bar view. It's the example that
uses every kind of workbench contribution:

- a **decoration type**, for the highlighting;
- a **side bar view**, listing each document's TODOs (choose one to go to it);
- a **status bar item**, counting them;
- a **keybinding**: `Ctrl+Alt+T` runs **Go to Next TODO**;
- a **context menu item** in the editor: **Insert TODO Comment**.

## Settings

`keywords` is a comma-separated list of the words that mark a TODO (`TODO,FIXME` by default).
